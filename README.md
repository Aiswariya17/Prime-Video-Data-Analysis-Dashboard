Prime Video Data Analytics Dashboard

Project Overview

The Prime Video Data Analytics Dashboard is a data visualization project developed using Python. It provides valuable insights into Prime Video content through graphical representations and statistical analysis.

Dashboard Preview

 ![dashboad png](dashboad.png)

Features

- Content Distribution Analysis
- Genre-wise Content Insights
- Release Year Trends
- Ratings Analysis
- Country-wise Content Distribution
- Interactive Visualizations
- Summary Statistics

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

Dataset

The dashboard is built using a Prime Video dataset containing information about movies and TV shows, including genres, ratings, release years, countries, and other content attributes.

Objective

The objective of this project is to analyze and visualize Prime Video content data to identify trends, patterns, and key insights through an effective dashboard.

Conclusion

This dashboard helps users explore content distribution, understand viewing trends, and gain meaningful insights from Prime Video data using data analytics techniques.
